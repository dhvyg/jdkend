# Awesome MCP Servers

Source: https://github.com/punkpeye/awesome-mcp-servers — one README with ~4,000 servers grouped by `### Category`. Each entry is `- [owner/repo](link) <badges> <icons> - description`. Icons: 🎖️ official, 🐍 Python, 📇 TypeScript/JS, 🏎️ Go, 🦀 Rust, ☁️ cloud service, 🏠 runs locally, 🍎/🪟/🐧 OS.

1. Fetch the list: `curl -sL https://raw.githubusercontent.com/punkpeye/awesome-mcp-servers/main/README.md`
2. Find the category heading or grep descriptions for the user's service name.
3. Prefer 🎖️ official servers from the service's own org, then active repos with many stars. Note 🏠 local vs ☁️ cloud.
4. Recommend 2–3 options with link, language, and the install command from that server's own README — never invent config.

MCP servers run code and get access to data or accounts. The list is community-submitted and not audited: say so, and never add one to settings without the user's explicit OK.
